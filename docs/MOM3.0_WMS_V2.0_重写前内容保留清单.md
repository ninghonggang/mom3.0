## 2. 必须保留的"业务灵魂"清单

### 2.1 9 大功能域(业务骨架,不能丢)

| # | 域 | 业务价值 | V2.0 § 1.2 写法 |
|---|----|---------|---------------|
| 1 | 基础档案 | 仓库/库区/库位/物料/容器 5 张主档 | 1 行 1 域 |
| 2 | 库内作业 | 盘点/移库/调账 3 个作业 | 1 行 1 域 |
| 3 | 入库管理 | 采购/生产/销售退货 4 类入库 | 1 行 1 域 |
| 4 | 出库管理 | 销售发货/领料/退料 3 类出库 | 1 行 1 域 |
| 5 | 库存管理 | 库存台账/批次/有效期 | 1 行 1 域 |
| 6 | 容器管理 | 容器主从表/生命周期 | 1 行 1 域 |
| 7 | AGV 调度 | 与 AGV 系统的接口 | 1 行 1 域 |
| 8 | 质检管理 | 库存质检/抽检 | 1 行 1 域 |
| 9 | 标签打印 | 条码/箱码/批次码 | 1 行 1 域 |

### 2.2 18 张表(数据骨架)

**主档类(6)**:`wms_warehouse` / `wms_areabasic` / `wms_location` / `wms_itembasic` / `wms_container_main` / `wms_container_detail`

**库存类(3)**:`wms_balance` / `wms_balance_history` / `wms_batch`

**作业类(9)**:`wms_putaway_job` / `wms_putaway_record` / `wms_pick_job` / `wms_pick_record` / `wms_count_plan` / `wms_count_job` / `wms_count_record` / `wms_inventory_move_job` / `wms_count_adjust_request`

> V2.0 § 7.2 只列 8-10 张核心表字段,完整 DDL 引用代码侧 `mom-server/migrations/00xx_create_wms_*.sql`。

### 2.3 4 个集成关系(对其他模块的依赖)

| 集成方 | 方向 | 用途 | V2.0 § |
|--------|------|------|---------|
| **MES** | 双向 | MES 报工完成 → WMS 触发入库;MES 领料 → WMS 出库 | § 2.2 + § 10.1/10.2 |
| **SCP** | 入站 | 销售订单 → WMS 销售发货;采购订单 → WMS 采购入库 | § 2.2 + § 10.1/10.2 |
| **Report** | 出站 | WMS 库存数据 → 报表 | § 2.2 + § 10.1 |
| **AGV** | 双向 | WMS 拣货任务 → AGV 执行;AGV 状态 → WMS | § 2.2 + § 10.1/10.2 |

### 2.4 3 个核心业务流程(必须 Mermaid 化)

- **入库流程**(§ 5.1):采购入库 / 生产入库 / 退货入库 3 路径
- **出库流程**(§ 5.2):销售发货 / 领料 / 退料 3 路径
- **盘点流程**(§ 5.3):盘点计划 → 盘点任务 → 盘点记录 → 调账

## 3. 必砍清单(V2.0 不要这些)

| 类别 | 旧版内容 | 砍的理由 |
|------|---------|---------|
| Java 特定 | `@TableName` / `@KeySequence` / `BaseDO` / MyBatis-Plus | MOM 3.0 是 Go + GORM |
| 控制器细节 | doController 模式 / 9 大模块控制器列表 | 砍,V2.0 不列控制器细节 |
| VO 对象 | XxxCreateReqVO / XxxUpdateReqVO 等 | 砍,V2.0 § 8.2 用 JSON 示例 |
| 通用设计模式 | § 4.1 | 砍,GORM 用 tag 表达 |
| 11.1 V1.0/V1.1 版本记录 | 旧版元信息 | 砍,V2.0 § 13.1 新写 |
| 11.2 章节完成状态 | 旧版 metadata | 砍,V2.0 不需要 |
| 错误码 § 8 旧定义 | Java 时代 errno | 砍,引用 mdm_errno 字典 |
| § 6 关键技术实现 | 高级搜索/幂等/导入校验等 Java 实现 | 砍,V2.0 § 11 可观测性 + § 8.4 幂等/限流 |
| 完整 API 清单 | 5000+ 行路由列表 | 大幅去重,留 100+ 核心 |
